Política de Privacidade

Última atualização: 20 de agosto de 2026

O DarkFactoryAI é uma ferramenta de automação de uso pessoal, mantida por um único desenvolvedor, usada para gerar e publicar vídeos nos canais listados na página inicial. Esta política explica que dados são tratados e como.

O que este sistema faz

O DarkFactoryAI gera conteúdo de vídeo (roteiro, narração, imagem e legenda) e publica esse conteúdo diretamente nas contas de YouTube e TikTok controladas pelo próprio desenvolvedor, usando as APIs oficiais dessas plataformas.

Dados tratados

  • Tokens de acesso OAuth (YouTube e TikTok), usados exclusivamente para publicar vídeos nas contas autorizadas pelo próprio desenvolvedor.
  • Arquivos de vídeo, áudio e texto gerados pelo próprio sistema, armazenados localmente até a publicação.

Este sistema não coleta, processa ou armazena dados pessoais de terceiros. Não há cadastro de usuários, formulário público ou coleta de dados de visitantes deste site além do necessário para o funcionamento básico do navegador.

Compartilhamento de dados

Nenhum dado é vendido, alugado ou compartilhado com terceiros. Os únicos destinos dos dados gerados são as próprias plataformas de publicação (YouTube, TikTok), através de suas APIs oficiais, para o único propósito de publicar o conteúdo.

Retenção e exclusão

Tokens de acesso podem ser revogados a qualquer momento diretamente nas configurações da conta Google ou TikTok correspondente. Arquivos locais gerados pelo sistema podem ser apagados a qualquer momento pelo desenvolvedor.
